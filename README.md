# Nexora Technologies — Multi-Brand SaaS Website Ecosystem

> **"Technology that moves you forward."**  
> An enterprise-grade, multi-brand SaaS portfolio platform built with Apple/Linear-inspired minimalism. It showcases three independent product lines under a unified brand and design system.

---

## 2. Key Features

- **Apple / Linear Design System**: Restrained monochrome surfaces (`#FFFFFF` base, `#F8F9FB` secondary), subtle 1px border lines, Geist typography, and intentional accent color placement.
- **Dynamic Product Workbenches**:
  - Nexora Learn: Interactive curriculum module inspector.
  - Nexora Cloud: Real-time FinOps cost simulator dynamically calculating savings based on node cluster slider.
  - Nexora Events: Interactive ticket tier selector with real-time pass count adjustment.
- **Pricing Engine**: Monthly/Annual billing switcher with dynamic 20% discount recalculation across Starter, Professional, and Enterprise tiers.
- **Lead Capture & Inquiries**: Form validation with client-side feedback and simulated database persistence.
- **Interactive Admin Console**: Lead telemetry dashboard and system status monitoring.
